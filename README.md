# General Utility Drone
A Drone with multiple interchangeable modules 

# Why I've Built it

I've always liked drones , I saw there are no good (and cheap) drones that let you do *whatever* you want . That's why i built a general utility drone , Whatever you want **Your** drone to do is possible . All modules interface with the drone using 4 M6 Screws and a 70x70 mm plate

# Getting Started 

## 3D Printed Parts
* Frame
* Required Modules' parts
